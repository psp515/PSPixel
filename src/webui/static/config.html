System

normal — every channel runs: Wi-Fi, MQTT, this dashboard.

mqtt-ssl — MQTT over TLS only; the dashboard and Web API are not started, freeing the memory the encrypted connection needs. Requires MQTT enabled with a server and SSL turned on, otherwise the device boots normal. To change settings later, hold the device button ~5 seconds.

config — setup mode, never a default: hold the button ~5 seconds until the LEDs turn off, and the device restarts onto its setup access point with this dashboard. Restarting from config mode returns to the default mode.
